## Preparation Checklist

Use this checklist before writing or modifying methods:

- Ensure all referenced structs are bound in `var _ = def.Init(...)`.
- Ensure fields used in SQL have `db:"column_name"` tags.
- Ensure primary key fields have `primary_key:"true"` tags.
- Ensure relation fields have `db:"-"` with `foreign_key` and optionally `inverse` tags.
- Ensure method params include all dynamic values used in `def.Filter`, `def.Set`, `def.Limit`, `def.Offset`.

## Project Setup

### File structure with build tags

```
myrepo/
├── model.go              # Struct definitions with db/foreign_key tags (no build tag)
├── storage.go            # //go:build <tag>  — DSL source: def.Init, interface, querier, DSL methods
├── storage_impl.go       # //go:build !<tag> — Business logic using generated symbols
├── storage_gen.go        # //go:build !<tag> — Generated by def (intermediate + SQL comments)
└── xxxstore_impl.go      # //go:build !<tag> — Generated by defc (actual SQL execution)
```

### Source file template

```go
//go:build mytag

//go:generate def generate --tags mytag --defc-generate -o storage_gen.go .

package mypackage

import (
    "context"
    "database/sql"

    "github.com/x5iu/def"
)

var _ = def.Init(
    def.BindTable[User]("users"),
    def.BindTable[Project]("projects"),
)

type MyStore interface {
    FindUser(ctx context.Context, id int64) (*User, error)
    CreateUser(ctx context.Context, user *User) (sql.Result, error)
}

type myRepo struct{}

func (r *myRepo) FindUser(ctx context.Context, id int64) (user *User, err error) {
    def.Query(
        def.Filter(user.ID == id),
    )
    return nil, nil
}

func (r *myRepo) CreateUser(ctx context.Context, user *User) (sql.Result, error) {
    def.Create(user)
    return nil, nil
}
```

### Business logic file template

```go
//go:build !mytag

package mypackage

import "context"

type myStorage struct {
    store MyStore // generated interface, implemented by defc
}

func newMyStorage(drv, dsn string) *myStorage {
    return &myStorage{store: NewMyStore(drv, dsn)}
}

func (s *myStorage) GetUserWithProjects(ctx context.Context, id int64) (*User, error) {
    user, err := s.store.FindUser(ctx, id)
    if err != nil {
        return nil, err
    }
    ctx = WithCache(ctx)
    if err := user.Callback(ctx, s.store); err != nil {
        return nil, err
    }
    return user, nil
}
```

## Struct Tags

### Column fields

```go
type User struct {
    ID        int64     `db:"id" primary_key:"true" auto_increment:"true"`
    Name      string    `db:"name"`
    CreatedAt time.Time `db:"created_at"`
}
```

Fields with `auto_increment:"true"` are excluded from entity-mode INSERT (`def.Create(entity)`).

```go
// Without auto_increment: INSERT includes id column
// With auto_increment:"true": INSERT omits id column, database assigns it
```

### Relations (foreign_key + inverse)

```go
type Project struct {
    ID     int64  `db:"id" primary_key:"true"`
    UserID int64  `db:"user_id"`
    Name   string `db:"name"`

    User *User `db:"-" foreign_key:"user_id" inverse:"Projects"`
}

type User struct {
    ID   int64  `db:"id" primary_key:"true"`
    Name string `db:"name"`

    Projects []*Project `db:"-"`
}
```

- `foreign_key:"user_id"` on `Project.User`: Project belongs-to User via `user_id` column.
- `inverse:"Projects"` tells def that `User.Projects` is the has-many side.
- def generates: `getUserByID()`, `getProjectsByUserID()`, and `Callback` methods on both structs.

## SELECT Patterns

### Select all with filter

```go
func (q *querier) GetUserByID(ctx context.Context, id int64) (user *User, err error) {
    def.Query(
        def.Filter(user.ID == id),
    )
    return nil, nil
}
```

### Select specific columns

```go
func (q *querier) GetUserBasic(ctx context.Context, id int64) (name string, age int, err error) {
    var user User
    def.Query(
        def.Column(user.Name),
        def.Column(user.Age),
        def.Filter(user.ID == id),
    )
    return "", 0, nil
}
```

### Use functions in filters

```go
func (q *querier) GetActiveCount(ctx context.Context) (count int64, err error) {
    var user User
    def.Query(
        def.Column(def.Count[int64](user.ID)),
        def.Filter(user.Status == "active"),
    )
    return 0, nil
}
```

### Use pagination

```go
func (q *querier) ListUsers(ctx context.Context, limit, offset int) (users []*User, err error) {
    def.Query(
        def.Limit(limit),
        def.Offset(offset),
    )
    return nil, nil
}
```

### Filter through foreign_key (subquery)

```go
func (q *querier) FindProjectsByUserName(ctx context.Context, userName string) ([]*Project, error) {
    def.Query(
        def.Filter(project.User.Name == userName),
    )
    return nil, nil
}
```

Generates: `WHERE user_id IN (SELECT id FROM users WHERE name = ${userName})`

## INSERT Patterns

### Entity mode insert

```go
func (q *querier) CreateUser(ctx context.Context, user *User) (sql.Result, error) {
    def.Create(user)
    return nil, nil
}
```

### Field mode insert

```go
func (q *querier) CreateUser(ctx context.Context, name string, age int) (sql.Result, error) {
    var user User
    def.Create(
        def.Set(user.Name, name),
        def.Set(user.Age, age),
    )
    return nil, nil
}
```

## UPDATE Patterns

### Field mode update

```go
func (q *querier) UpdateUserName(ctx context.Context, id int64, name string) (sql.Result, error) {
    var user User
    def.Update(
        def.Set(user.Name, name),
        def.Filter(user.ID == id),
    )
    return nil, nil
}
```

### Arithmetic/time expression update

```go
func (q *querier) BumpAttempt(ctx context.Context, id int64) (sql.Result, error) {
    var retry SettlementRetry
    def.Update(
        def.Set(retry.Attempts, retry.Attempts+1),
        def.Set(retry.UpdatedAt, postgres.Now()),
        def.Filter(retry.ID == id),
    )
    return nil, nil
}
```

### CTE + UPDATE FROM + RETURNING

```go
func (q *querier) ClaimDueRetries(ctx context.Context, limit int) ([]*SettlementRetry, error) {
    var sr SettlementRetry
    var due SettlementRetry

    def.Update(
        def.With(
            "due",
            def.From(sr),
            def.Column(sr.ID),
            def.Filter(sr.DoneAt == nil),
            def.Filter(sr.DeadAt == nil),
            def.Filter(sr.NextRetryAt <= postgres.Now()),
            def.OrderBy(
                def.Asc(sr.NextRetryAt),
                def.Asc(sr.ID),
            ),
            def.Limit(limit),
            postgres.ForUpdateSkipLocked(),
        ),
        def.Set(sr.Attempts, sr.Attempts+1),
        def.Set(sr.NextRetryAt, postgres.Now()+postgres.Interval("10 minutes")),
        def.Set(sr.UpdatedAt, postgres.Now()),
        def.From("due"),
        def.Filter(sr.ID == due.ID),
        postgres.Returning(sr.ID, sr.RequestID, sr.Payload, sr.Attempts),
    )
    return nil, nil
}
```

Expected SQL shape:

```sql
WITH due AS (
    SELECT id
    FROM settlement_retries
    WHERE done_at IS NULL
      AND dead_at IS NULL
      AND next_retry_at <= NOW()
    ORDER BY next_retry_at ASC, id ASC
    LIMIT ${limit}
    FOR UPDATE SKIP LOCKED
)
UPDATE settlement_retries
SET attempts = attempts + 1,
    next_retry_at = NOW() + INTERVAL '10 minutes',
    updated_at = NOW()
FROM due
WHERE settlement_retries.id = due.id
RETURNING id, request_id, payload, attempts
```

## DELETE Patterns

### Safe delete with filter

```go
func (q *querier) DeleteUser(ctx context.Context, id int64) (sql.Result, error) {
    var user User
    def.Delete(def.Filter(user.ID == id))
    return nil, nil
}
```

`def.Delete(...)` requires at least one `def.Filter(...)`.

## Foreign Key Relations

### Belongs-to (many-to-one)

Place `foreign_key` on the child struct's relation field:

```go
type Project struct {
    ID     int64  `db:"id" primary_key:"true"`
    UserID int64  `db:"user_id"`
    Name   string `db:"name"`

    User *User `db:"-" foreign_key:"user_id" inverse:"Projects"`
}
```

def generates: `getUserByID(ctx, id) (*User, error)`

### Has-many (one-to-many)

The parent struct declares the slice field with `db:"-"`. The `inverse` tag on the child connects them:

```go
type User struct {
    ID   int64  `db:"id" primary_key:"true"`
    Name string `db:"name"`

    Projects []*Project `db:"-"`
}
```

def generates: `getProjectsByUserID(ctx, userID) ([]*Project, error)`

### Chained relations

```go
type Task struct {
    ID        int64 `db:"id" primary_key:"true"`
    ProjectID int64 `db:"project_id"`

    Project *Project `db:"-" foreign_key:"project_id" inverse:"Tasks"`
}
```

Callback chain: `User.Callback` → loads `Projects` → each `Project.Callback` → loads `Tasks`.

## Callback Loading

### Basic usage

```go
// Create cache context (required)
ctx = WithCache(ctx)

// Load all relations for a single entity
if err := user.Callback(ctx, store); err != nil {
    return err
}
// user.Projects is now populated

// Load relations for a slice
for _, project := range projects {
    if err := project.Callback(ctx, store); err != nil {
        return err
    }
}
```

### Key points

- `WithCache(ctx)` is **required** before calling any `Callback`. Without it, `Callback` returns `ErrCallbackCacheRequired`.
- Cache prevents circular loading (e.g., User → Projects → User → ...) and N+1 queries.
- `Callback` loads **all** relation fields on the struct (both belongs-to and has-many).
- Slice type aliases (e.g., `type Projects []*Project`) are auto-generated with their own `Callback` method.

## PostgreSQL Patterns

### RETURNING struct rows

```go
func (q *querier) CreateAndGetUser(ctx context.Context, name string) (user *User, err error) {
    var userRow User
    def.Create(
        def.Set(userRow.Name, name),
        postgres.Returning(),
    )
    return nil, nil
}
```

### UPSERT

```go
func (q *querier) UpsertRole(ctx context.Context, name string) (role *Role, err error) {
    var roleRow Role
    def.Create(
        def.Set(roleRow.Name, name),
        postgres.OnConflict(roleRow.Name).DoUpdate(
            def.Set(roleRow.Name, postgres.Excluded(roleRow.Name)),
        ),
        postgres.Returning(),
    )
    return nil, nil
}
```

## SQL-to-DSL Mapping Checklist

Use this deterministic sequence when converting hand-written SQL:

1. Identify statement type: SELECT / INSERT / UPDATE / DELETE.
2. Identify target table type by `def.BindTable[T]("table")`.
3. Create or reuse a typed variable (`var user User`) for field paths.
4. Convert select list:
- `SELECT *` => no `def.Column`.
- explicit columns/functions => one `def.Column(...)` per item.
5. Convert predicates to `def.Filter(...)` with native Go operators.
6. Convert dynamic values to method parameters and reference by identifier.
7. Add pagination with `def.Limit` / `def.Offset` if SQL needs it.
8. Add PostgreSQL extras (`Returning`, `OnConflict`, `With`, `From`, `Now`, `Interval`) only when needed.
9. Run `def generate` and inspect generated SQL comment.
10. Run tests/lint and iterate until SQL shape matches intent.
